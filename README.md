# 🛡️ Toolkit de Auditoría de Red en PowerShell

Colección de herramientas nativas en PowerShell diseñadas para la auditoría de red local, reconocimiento de hosts y ciberseguridad defensiva.

## 🛠️ Herramientas Incluidas

### 1. `PortScanner.ps1` (Escáner de Puertos TCP)
Identifica servicios y puertos comunes escuchando en un host objetivo (local o remoto).

```powershell
.\PortScanner.ps1 -TargetIP 127.0.0.1
